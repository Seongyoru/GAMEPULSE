# Source research — Zenless Zone Zero (HoYoverse) and Neverness to Everness (Hotta Studio)

- **Date:** 2026-10-02
- **Method:** 139 polite HTTP GETs over ~25 min (≥1.2 s apart; browser UA tagged `GAMEPULSE-research`), no logins,
  nothing bypassed. Official pages plus the data those pages load (HoYoverse `content_v2` JSON, the HoYoLAB news
  list, NTE's server-rendered HTML and footer/legal pages). 3 web searches, used only to find official pages.
  Article bodies were read in memory for short snippets and not saved.
- **Labels:** **VERIFIED** seen on an official page or in data an official page loads · **INFERRED** derived from
  verified data (method stated) · **UNVERIFIED** not confirmed (e.g. only seen in secondary sources).
- **Status:** research input for `docs/DATA_SOURCES.md` / `docs/LEGAL_NOTES.md`. Not legal advice.

## Key conclusions

1. **Both games are live in Korea. NTE is not in testing.**
   - **ZZZ:** global launch 2024-07-04 on all platforms; current version **3.2** since 2026-09-09. Platforms: PC
     (HoYoPlay), Android/iOS, PS5/PS5 Pro, Xbox Series X|S (VERIFIED).
   - **NTE (이환):** global launch, Korea included, on **2026-04-29 11:00 (UTC+8) = 12:00 KST**. Platforms at
     launch: Windows PC, iOS, Android, macOS, Google Play PC, PS5/PS5 Pro. Steam, Epic Games Store and Galaxy Store
     were added on 2026-07-08. Current version **1.4** since 2026-09-30 (VERIFIED).
   - Neither game has a Korea-only server.
2. **No documented public API, RSS/Atom feed or developer program for either game** (VERIFIED by absence).
   - ZZZ news is built from undocumented JSON (`sg-public-api-static.hoyoverse.com/content_v2_user/app/3e9196a4b9274bd7/…`).
   - NTE news is static HTML plus an undocumented `include/newsData*.js`.
   - Neither should be automated.
3. **robots.txt does not restrict crawling.** `zenless.hoyoverse.com` returns 404, `nte.perfectworld.com` returns an
   empty 200, and HoYoLAB only has `Disallow: /genshin`.
4. **The terms forbid automated collection without written permission for both games.**
   - **ZZZ (English):** the ToS (updated 2026-03-24) §7(c) says content may not be "… republished, downloaded,
     scraped, displayed …" without COGNOSPHERE's "express prior written permission". §3(b)(vi) bans commercial use.
   - **ZZZ (Korean):** the 이용약관 (effective 2025-09-04) bans copying obtained information for other purposes or
     giving it to third parties (제8조 8)) and commercial reuse (제28조 2)).
   - **NTE (English):** the ToS (effective 2026-07-08) §3.4(s) bans "any robot, spider, crawler or other automatic
     device … [that] scrapes …" **"or engage in any manual process to do the same"**. §6.1(b)(iv) bans "data mining,
     robots".
   - **NTE (Korean):** the 이용약관 (effective 2026-07-08) 제4조② bans 복제·전송·전시 of any content without
     authorisation.
   - → Website collectors **DISABLED**, facts ingested by hand with links. For NTE, even manual monitoring is
     literally covered by §3.4(s), so get legal review or written permission first.
   - Korean contacts: ZZZ — 주식회사 코그노스피어코리아, kr_mkt_global@hoyoverse.com. NTE — domestic agent 주식회사
     퍼펙트월드코리아 (contact in the Korean 이용약관), or nte.legal@perfectworld.com.
5. **Time labels.** Both publishers print global times in UTC+8 in English. Korean notices convert them to KST
   (+1 h) and add an explicit "(KST)" label. Exceptions the parser must handle:
   - ZZZ Korean notices up to at least 2026-01-14 mix "(KST)" with unconverted "(서버 시간)" values, sometimes in the
     same line. At least one put the "(서버 시간)" label on a KST value. Notices from 2026-03 onward use "(KST)".
   - ZZZ Korean notices write "24:59(KST)", meaning 00:59 the next day.
   - NTE keeps per-server windows as "(서버 시간)" with the same numbers as the English "(server time)".
   - NTE's Korean launch time "12:00" has no label.
6. **Resets.**
   - **ZZZ** (official wording VERIFIED for named features; the general daily/weekly reset INFERRED from it; current
     biweekly anchors UNVERIFIED):
     - daily reset 04:00 server time (05:00 KST);
     - weekly reset Monday 04:00 (05:00 KST);
     - Shiyu Defense Critical Node and Deadly Assault every 2 weeks, Friday 04:00 (05:00 KST).
   - **NTE:** no official reset statement found. Windows labelled "(server time)" run Monday 05:00 → Monday 04:59,
     which suggests daily/weekly boundaries at 05:00 server time (INFERRED). Server UTC offsets are not stated
     officially (UNVERIFIED).
