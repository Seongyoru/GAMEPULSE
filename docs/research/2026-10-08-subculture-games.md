# Subculture games for Korea (researched 2026-10-08)

GAMEPULSE covers subculture (anime-style character-collection) games, mobile first (D-037). This note records why each
game was added or left out and where its facts come from. Official pages were read where they render without
JavaScript; namu.wiki and arca.live refused automated reads (403) and were not worked around, so some facts come from
search-result summaries, third-party reset trackers or community posts. Those are marked below and in each reset
rule's `notes`. **Every reset rule is UNVERIFIED** until someone checks it in game (RUNBOOK › Verifying reset rules).

Popularity comes from Korean store revenue charts (GamerScroll monthly integrated charts and its subculture chart,
2025-12 to 2026-10) and Gamemeca's 2026-06-05 report on new subculture launches. No public 2026 MAU data was found.

## Data access

None of these games publishes a public API or feed for notices. Their facts arrive through manual ingestion until a
publisher gives written permission for automated collection (LEGAL_NOTES, DATA_SOURCES). Several post official
notices on Naver Game lounges or Daum/Naver cafes, which are not publisher-operated domains; source URLs for those
need a policy decision before manual entries can cite them.
